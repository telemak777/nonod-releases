# NoNod Studio — releases

**NoNod Studio** is an AI image studio for Windows: the power of ComfyUI, without the nodes.

This repository only holds the installers. Download the latest version from
[Releases](https://github.com/telemak777/nonod-releases/releases/latest):

- `NoNod-x.y.z-setup.exe`: installer (per user, no admin rights). It updates itself.
- `NoNod-x.y.z-portable.exe`: portable version; it keeps its data in a `NoNod-data` folder next to it.

Requirements: Windows 10/11 x64, an NVIDIA graphics card, and ComfyUI (the app can install and manage its own).
